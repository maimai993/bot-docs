# 踢人

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat)

**指令名称**: 踢人

**功能描述**: 移除群成员功能

::: warning
本功能需要管理员或群主权限，请谨慎使用。
:::

## 使用方法

### 指令名称

```
踢人 <用户>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 用户 | @ | 是 | 要移除的群成员 | @群友 |
