# 禁言

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat)

**指令名称**: 禁言

**功能描述**: 群成员禁言管理

::: warning
本功能需要管理员或群主权限，请谨慎使用。
:::

## 使用方法

### 指令名称

```
禁言 <用户> [时长]
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 用户 | @ | 是 | 要禁言的群成员 | @群友 |
| 时长 | 数字 | 否 | 禁言时长（秒），不填为永久 | 60 |
