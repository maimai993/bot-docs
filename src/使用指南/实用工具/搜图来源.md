# 搜图来源

## 功能描述
根据图片搜索来源信息，识别图片出处和相关信息

## 使用方法

### 指令名称

```
搜图
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 图片 | 图片 | 是 | 要搜索来源的图片 | [图片](./搜图来源_示范.jpg) |
