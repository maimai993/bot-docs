# 定时命令

## 功能描述

在指定时间或按固定间隔自动执行一条指令，可用于群内定时提醒、定时推送等。

::: warning 权限
该指令需要 **权限 3** 才能使用。
:::

## 使用方法

### 指令名称

```
schedule <时间>
```

### 参数说明

| 参数 | 说明 |
|------|------|
| `<时间>` | 执行时间，支持自然语言时间与 cron 表达式 |
| `-- <command>` | 到点要执行的指令内容 |
| `/ <interval>` | 按固定间隔重复执行（需要权限 4） |
| `-l` | 列出当前已设置的定时任务 |
| `-e` | 编辑已有任务 |
| `-f` | 强制执行一次 |
| `-d <id>` | 删除指定 ID 的定时任务 |

该指令使用 koishi 官方的 `schedule` 语法，与 [@koishijs/plugin-schedule](https://schedule.koishi.chat/) 一致。
