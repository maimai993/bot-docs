# 大学查询

## 功能描述
查询大学基本信息，包括成立时间、占地面积、学校地址和简介

## 使用方法

### 指令名称

```
学校查询 <query>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| query | 文本 | 是 | 要查询的大学名称 | 清华大学 |
