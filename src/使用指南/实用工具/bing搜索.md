# bing搜索

## 功能描述
使用Bing搜索引擎进行网页搜索，返回前10个搜索结果

## 使用方法

### 指令名称

```
bing <keyword>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| keyword | 文本 | 是 | 要搜索的关键词 | 麦芽糖 |
