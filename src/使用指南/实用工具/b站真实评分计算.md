# B站真实评分计算

## 功能描述
获取B站番剧评论并计算真实评分

## 使用方法

### 指令名称

```
b站评分 <name>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| name | 文本 | 是 | 要查询的B站番剧名称或ID | 有兽焉 |
