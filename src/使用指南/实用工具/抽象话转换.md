# 抽象话转换

## 功能描述
将中文转换为emoji抽象话，或将抽象话还原为拼音

## 使用方法

### 指令名称

```
抽象话 <text>
还原抽象话 <text>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| text | 文本 | 是 | 要转换或还原的内容 | 需要被抽象的话语 |

## 使用示例

### 转换为抽象话

#### 将普通文本转换为抽象话
<chat-panel>
<chat-message nickname="麦麦" type="user">抽象话 需要被抽象的话语</chat-message>
<chat-message nickname="麦芽糖bot" type="bot">
‍⏭💊被🤡🐘💦🌸语
</chat-message>
</chat-panel>

#### 将中文句子转换为抽象话
<chat-panel>
<chat-message nickname="麦麦" type="user">抽象话 真的太抽象啦</chat-message>
<chat-message nickname="麦芽糖bot" type="bot">
💉💦太🤡🐘🌶！
</chat-message>
</chat-panel>

### 还原抽象话

#### 将抽象话还原为拼音
<chat-panel>
<chat-message nickname="麦麦" type="user">还原抽象话 ‍⏭💊被🤡🐘💦🌸语</chat-message>
<chat-message nickname="麦芽糖bot" type="bot">
‍-⏭-yao-被-chou-xiang-di/shui-hua-语
</chat-message>
</chat-panel>

#### 将复杂抽象话还原为拼音
<chat-panel>
<chat-message nickname="麦麦" type="user">还原抽象话 💉💦太🤡🐘🌶！</chat-message>
<chat-message nickname="麦芽糖bot" type="bot">
zhen-di/shui-太-chou-xiang-na/la-！
</chat-message>
</chat-panel>
