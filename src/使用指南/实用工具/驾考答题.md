# 驾考答题

## 功能描述

在群里进行驾驶理论考试（科目一/科目四）答题练习。

## 使用方法

### 指令名称

```
驾考答题
结束驾考答题
```

### 参数说明

| 指令 | 说明 |
|------|------|
| `驾考答题` | 开始驾驶理论考试答题 |
| `结束驾考答题` | 结束当前答题 |
