# 获取帮助

::: warning
部分指令不会出现在该列表中，具体参考[功能列表](/features)为准
:::
## 功能描述
以图片形式展示帮助信息

## 使用方法

### 指令名称

```
帮助 [指令]
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 指令 | 文本 | 否 | 获取指令的具体用法 | 帮助 |

### 使用示例

#### 获取指令列表
<chat-panel>
<chat-message nickname="麦麦" type="user">帮助</chat-message>
<chat-message nickname="麦芽糖bot" type="bot">
<span style="color: #575c63ff;">图片过长已隐藏</span>
</chat-message>
</chat-panel>
