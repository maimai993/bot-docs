# 天气查询

## 功能描述
获取今日或未来天气

## 使用方法

### 指令名称

```
天气 <city>
未来天气 <city>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| city | 文本 | 是 | 要查询天气的城市名称 | 北京 |
