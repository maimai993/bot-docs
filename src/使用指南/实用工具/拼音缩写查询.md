# 拼音缩写查询

## 功能描述
中文缩写词搜索
## 使用方法

### 指令名称

```
abbr <text>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| text | 文本 | 是 | 要查询的拼音缩写 | myt |
