# QQ官Bot链接

## 功能描述

获取 QQ 官方机器人的转换链接与配置指南，方便在手机 QQ 中配置机器人的全量消息与主动发言。

## 使用方法

### 指令名称

```
qqbot-guide
qqbot-url <官Bot的QQ号>
napcat-getuser <官Bot的QQ号>
```

### 参数说明

| 指令 | 说明 |
|------|------|
| `qqbot-guide` | 发送手机 QQ 机器人全量消息与主动发言设置指南 |
| `qqbot-url <官Bot的QQ号>` | 生成官方机器人的跳转链接 |
| `napcat-getuser <官Bot的QQ号>` | 在 NapCat 中获取官 Bot 的 UID |

### 可选参数

| 参数 | 说明 |
|------|------|
| `-u <botuin>` | 官 Bot 的 QQ 号 |
| `-i <botuid>` | 官 Bot 的 UID |
| `-g <groupcode>` | 群号 |

::: tip
`napcat-getuser` 需要在 NapCat 侧使用。
:::
