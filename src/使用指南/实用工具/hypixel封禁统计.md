# Hypixel封禁统计

## 功能描述
查询Hypixel服务器的封禁统计数据，包括Watchdog反作弊系统和客服封禁的统计信息

## 使用方法

### 指令名称

```
hypixel
hpbans
```

### 参数说明

该指令无需额外参数，直接调用即可获取最新的封禁统计数据。
