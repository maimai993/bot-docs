# AI 反推tag

## 功能描述
图片反推 AI 生成标签，角色识别，NSFW 程度判断

## 使用方法

### 指令名称

```
tagger.rec [图片]
```

### 参数说明

| 指令 | 说明 |
|------|------|
| tagger.rec [图片] | 反推标签、角色识别与 NSFW 判断 |
