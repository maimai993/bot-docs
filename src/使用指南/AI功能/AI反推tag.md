# AI 反推tag

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-waifu-diffusion-tagger)](https://www.npmjs.com/package/koishi-plugin-waifu-diffusion-tagger)

**指令名称**: tagger

**功能描述**: 图片反推 AI 生成标签，角色识别，NSFW 程度判断

## 使用方法

### 指令名称

```
tagger
tagger.rec [图片]
tagger.view-results <ID>
```

### 参数说明

| 指令 | 说明 |
|------|------|
| tagger | 上传图片进行反推 |
| tagger.rec [图片] | 反推标签、角色识别与 NSFW 判断 |
| tagger.view-results `<ID>` | 查看过往的识别结果 |
