# AI画图

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-gouqi-siliconflow-image)](https://www.npmjs.com/package/koishi-plugin-gouqi-siliconflow-image)

**指令名称**: kolors

**功能描述**: 基于硅基流动（SiliconFlow）的图像生成，输入提示词即可生成 AI 图片

## 使用方法

### 指令名称

```
kolors <提示词>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 提示词 | 文本 | 是 | 描述要生成的图片内容 | 一只小猫 |
