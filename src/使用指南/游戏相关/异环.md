# 异环

## 功能描述

异环（Neverness to Everness）数据查询：登录绑定、角色面板、体力推送、配队攻略、签到与抽卡记录等。

本页功能由 **GsCore（早柚核心）** 的 `NTEUID` 插件提供，共 66 条指令。

::: tip 使用前提
1. 群聊需已开启 GsCore 相关功能（部分指令需 @机器人 或加前缀触发）。
2. 大部分查询需要先完成账号绑定，绑定方式见下方「账号绑定」分类。
3. 指令中标注 `需CK` 的表示需要先向 GsCore 提供对应平台的 Cookie/CK。
4. 发送 `抽卡帮助` 可让机器人在群内直接渲染帮助图。
:::
