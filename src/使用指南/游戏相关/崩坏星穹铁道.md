# 崩坏星穹铁道

## 功能描述

崩坏：星穹铁道数据查询：绑定账号后可查询角色面板、忘却之庭、抽卡记录、开拓力、模拟宇宙等。

本页功能由 **GsCore（早柚核心）** 的 `StarRailUID` 插件提供，共 26 条指令。

::: tip 使用前提
1. 群聊需已开启 GsCore 相关功能（部分指令需 @机器人 或加前缀触发）。
2. 大部分查询需要先完成账号绑定，绑定方式见下方「账号绑定」分类。
3. 指令中标注 `需CK` 的表示需要先向 GsCore 提供对应平台的 Cookie/CK。
4. 发送 `崩坏星穹铁道帮助` 可让机器人在群内直接渲染帮助图。
:::

## 指令前缀

本插件支持的触发前缀：

| 前缀 | 说明 |
| ---- | ---- |
| `sr` | 该插件注册的触发前缀 |

触发方式以「指令列表」中的 **示例** 列为准：示例里带了前缀的，实际发送时就需要带上。
