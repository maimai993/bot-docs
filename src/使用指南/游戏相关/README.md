# 游戏相关

麦芽糖bot 通过 **GsCore（早柚核心）** 接入了一批主流游戏的数据查询插件，绑定账号后即可在群内直接查询角色面板、战绩、抽卡记录、体力等数据，结果以图片形式返回。

## 使用说明

1. **触发前缀**：每个游戏插件都有自己的注册前缀（如原神 `gs`、星铁 `sr`、王者 `王者`）。具体以各页面「指令列表」的**示例**列为准——示例里带了前缀的，实际发送时就要带上。
2. **账号绑定**：大部分查询需要先绑定账号，请先查看对应游戏页里的「绑定账号 / 基础服务」分类。
3. **CK / SK**：部分平台查询需要额外的 Cookie（CK）或 Stoken（SK）才能使用，页面中已用 `需CK`、`需SK` 标注。
4. **管理员指令**：标注 `需管理员` 的指令仅管理员可用。
5. **获取帮助**：发送对应游戏的帮助指令（如 `原神帮助`、`王者帮助`）可让机器人在群内直接渲染帮助图。
6. **示例图片**：各游戏页的「使用示例」章节正在陆续补充。

::: tip 关于 GsCore
GsCore（早柚核心）是这一整套游戏查询功能的后端核心，它还提供了一批与游戏无关的通用指令（状态、备份、插件管理、权限管理等），详见 **[GsCore 说明](./GsCore说明.md)**。
:::

## 通用游戏信息检索

除游戏内数据查询外，机器人还支持检索游戏的基础信息（简介、评分、折扣等）：

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `查询 <游戏名>` | 检索游戏名称，返回游戏基础信息 | `查询 原神` |
| `id <appid>` | 通过 AppID 反查游戏 | `id 570` |
| `打折游戏` | 查询当前打折的游戏 | `打折游戏` |
