# CS2

## 概述

**功能描述**: 查询 CS2（Counter-Strike 2）游戏信息，包括折扣、简介、评分等

## 使用方法

```
查询 CS2
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 游戏名 | 文本 | 是 | 要查询的游戏名称 | CS2 |
