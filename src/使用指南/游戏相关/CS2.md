# CS2

## 功能描述

CS2 战绩查询：支持完美平台、5E 平台的战绩与数据查询。

本页功能由 **GsCore（早柚核心）** 的 `CS2UID` 插件提供，共 17 条指令。

::: tip 使用前提
1. 群聊需已开启 GsCore 相关功能（部分指令需 @机器人 或加前缀触发）。
2. 大部分查询需要先完成账号绑定，绑定方式见下方「账号绑定」分类。
3. 指令中标注 `需CK` 的表示需要先向 GsCore 提供对应平台的 Cookie/CK。
4. 发送 `帮助` 可让机器人在群内直接渲染帮助图。
:::

## 指令前缀

本插件支持的触发前缀：

| 前缀 | 说明 |
| ---- | ---- |
| `cs` | 该插件注册的触发前缀 |
| `csgo` | 该插件注册的触发前缀 |
| `cs2` | 该插件注册的触发前缀 |

触发方式以「指令列表」中的 **示例** 列为准：示例里带了前缀的，实际发送时就需要带上。

## 指令列表

### 基础服务（3 条）

需要先绑定uid

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `绑定uid` | 绑定你的steam UID | `绑定uid 123456` |
| `删除uid` | 删除你的steam UID | `删除uid 123456` |
| `切换uid` | 切换你的steam UID | `切换uid123456` |

### 完美平台服务（5 条）

默认查完美绑定战绩，也可以后带uid

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `查询(完美)` | 查询cs完美平台数据一览 · `需CK` | `查询` |
| `查询官匹` | 查询cs官匹数据一览 · `需CK` | `查询官匹` |
| `好友码` | 查询cs官匹好友码 · `需CK` | `好友码` |
| `库存` | 查询steam里cs库存，最多显示20个 · `需CK` | `库存` |
| `对局记录` | 查询对局记录，可以带关键词官匹，天梯等等，不带默认完美平台记录 · `需CK` | `对局记录天梯` |

### 5E平台查询（2 条）

查5E平台绑定战绩，也可以后带uid

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `查询5e` | 查询cs 5e平台数据一览 · `需SK` | `查询5e` |
| `搜索5e` | 搜索cs 5e平台用户信息 · `需SK` | `搜索5e` |

### 攻略服务（1 条）

游戏攻略相关查询

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `道具` | 查询道具攻略 | `道具沙2 匪家 A大 过点烟` |

### 其他服务（2 条）

一些杂项服务

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `帮助` | 呼出该帮助界面 | `帮助` |
| `搜索` | 通过完美平台名字或steamid搜索用户 | `搜索爱丽数码` |

### 管理员功能（4 条）

游戏攻略相关查询

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `下载全部资源` | 下载完整资源(非必要) · `需管理员` | `下载全部资源` |
| `添加uid` | 作为完美数据请求的uid · `需管理员` | `添加uid 123456` |
| `添加tk` | 作为完美数据请求的token · `需管理员` | `添加tk abcd5epio` |
| `添加sk` | 作为5e数据请求的token · `需管理员` | `添加sk abcd5epio` |
