# 舞萌DX

## 功能描述

舞萌DX（maimai）查歌与成绩查询：定数查歌、随歌、今日舞萌、分数线、B40/B50 等。

本页功能由 **GsCore（早柚核心）** 的 `maimai_plugin` 插件提供，共 12 条指令。

::: tip 使用前提
1. 群聊需已开启 GsCore 相关功能（部分指令需 @机器人 或加前缀触发）。
2. 大部分查询需要先完成账号绑定，绑定方式见下方「账号绑定」分类。
3. 指令中标注 `需CK` 的表示需要先向 GsCore 提供对应平台的 Cookie/CK。
4. 发送 `舞萌帮助 / mai帮助` 可让机器人在群内直接渲染帮助图。
:::

## 指令前缀

本插件支持的触发前缀：

| 前缀 | 说明 |
| ---- | ---- |
| `mai` | 该插件注册的触发前缀 |
| `舞萌` | 该插件注册的触发前缀 |

触发方式以「指令列表」中的 **示例** 列为准：示例里带了前缀的，实际发送时就需要带上。

## 指令列表

### 查歌服务（5 条）

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `定数查歌 <定数>` | 按定数查询歌曲（别名：inner_level） | `定数查歌13.5` |
| `查歌 <关键词>` | 按关键词搜索歌曲 | `查歌夜驱` |
| `随个[dx/sd/标准][难度][等级]` | 随机抽取一首歌曲 | `随个dx紫14` |
| `<难度>id<编号>` | 按 id 查询歌曲，难度可选绿/黄/红/紫/白 | `紫id1234` |
| `maimai什么<关键词>` | 模糊询问歌曲信息 | `maimai什么夜驱` |

### 成绩服务（3 条）

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `b40` | 查询 Best 40 成绩 | `b40` |
| `b50` | 查询 Best 50 成绩 | `b50` |
| `分数线` | 查询各段位分数线 | `分数线` |

### 其他服务（4 条）

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `今日舞萌 / 今日mai` | 查看今日舞萌推荐 | `今日舞萌` |
| `舞萌帮助 / mai帮助` | 呼出舞萌帮助菜单 | `舞萌帮助` |
| `检查mai资源` | 检查舞萌资源是否完整 | `检查mai资源` |
| `强制检查mai资源` | 强制重新下载舞萌资源 | `强制检查mai资源` |
