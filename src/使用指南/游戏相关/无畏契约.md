# 无畏契约

## 功能描述

无畏契约数据查询：账号绑定、战绩查询与商店订阅等。

本页功能由 **GsCore（早柚核心）** 的 `VAUID` 插件提供，共 11 条指令。

::: tip 使用前提
1. 群聊需已开启 GsCore 相关功能（部分指令需 @机器人 或加前缀触发）。
2. 大部分查询需要先完成账号绑定，绑定方式见下方「账号绑定」分类。
3. 指令中标注 `需CK` 的表示需要先向 GsCore 提供对应平台的 Cookie/CK。
4. 发送 `帮助` 可让机器人在群内直接渲染帮助图。
:::

## 指令前缀

本插件支持的触发前缀：

| 前缀 | 说明 |
| ---- | ---- |
| `va` | 该插件注册的触发前缀 |

触发方式以「指令列表」中的 **示例** 列为准：示例里带了前缀的，实际发送时就需要带上。

## 指令列表

### 基础服务（4 条）

需要先绑定uid

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `扫码登录` | 扫码登录后会自动绑定 | `扫码登录` |
| `绑定uid` | 绑定你的无畏契约uid | `绑定uid 123456` |
| `删除uid` | 删除你的无畏契约uid | `删除uid 123456` |
| `切换uid` | 切换你的无畏契约uid | `切换uid 123456` |

### 查询服务（2 条）

查询个人主页信息，也可以后带uid

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `查询` | 查询个人赛季数据 · `需CK` | `查询` |
| `商店` | 查询每日商店信息 · `需CK` | `商店` |

### 订阅服务（2 条）

战绩订阅推送，每5分钟检查一次新战绩

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `订阅` | 开启战绩订阅推送，有新战绩时自动通知 · `需CK` | `订阅` |
| `取消订阅` | 关闭战绩订阅推送 | `取消订阅` |

### 其他服务（2 条）

一些杂项服务

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `帮助` | 呼出该帮助界面 | `帮助` |
| `搜索` | 搜索个人uid,关键词为掌瓦的id或者名字 · `需CK` | `搜索 爱丽数码` |

### 管理员功能（1 条）

其他

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `添加ck` | 作为数据请求的token · `需管理员` | `添加ck clientxxx` |
