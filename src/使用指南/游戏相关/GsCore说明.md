# GsCore 说明

**GsCore（早柚核心）** 是麦芽糖bot 游戏查询功能的后端核心：它统一管理各个游戏的账号绑定、数据缓存与图片渲染，再由 Koishi 侧的 `gscore-adapter` 适配器接入群聊。

游戏相关页面里的原神 / 星铁 / 王者荣耀等功能，全部由 GsCore 及其插件提供。

## 触发前缀

GsCore 自身的核心指令使用 `core` / `Core` / `CORE` 作为前缀。

::: warning 注意
下面列出的是 Core 自身的运维类指令。**普通用户日常只需要用到 `core帮助` 和账号绑定相关的指令**，其余多为管理员用途。Core 指令会随版本更新变化，最准确的方式是直接发送 `core帮助` 让机器人渲染帮助图。
:::

## 核心指令

### 帮助与状态

| 指令 | 说明 |
| ---- | ---- |
| `core帮助` | 渲染 GsCore 帮助图，包含当前已安装的插件与指令 |
| `core信息` / `corestatus` | 查看 Core 运行状态 |
| `core绑定信息` | 查看自己的绑定信息 |
| `core给我发消息` | 让 Core 向当前会话发一条测试消息 |

### 账号与登录

| 指令 | 说明 |
| ---- | ---- |
| `core扫码登陆` / `core扫码登录` | 通过扫码登录米游社等平台帐号 |
| `core添加` | 添加对应平台的 CK（仅私聊） |
| `core刷新全部CK` | 刷新全部已保存的 CK |
| `core刷新CK` | 刷新当前 CK |
| `core校验全部Cookies` | 校验全部 Cookies 是否有效 |
| `core校验全部Stoken` | 校验全部 Stoken 是否有效 |

### 插件管理（管理员）

| 指令 | 说明 |
| ---- | ---- |
| `core刷新插件列表` | 刷新可安装插件列表 |
| `core安装插件` | 安装插件 |
| `core卸载插件` | 卸载插件 |
| `core更新插件` / `core强制更新插件` | 更新单个插件 |
| `core全部更新` / `core全部强制更新` | 更新全部插件 |
| `core重载插件` / `core手动重载插件` | 重载插件 |
| `core更新依赖` | 更新依赖 |

### 配置与维护（管理员）

| 指令 | 说明 |
| ---- | ---- |
| `core查看配置` / `core设置配置` | 查看 / 修改插件配置 |
| `core查看插件` / `core设置插件` | 查看 / 修改插件开关 |
| `core查看命令` / `core设置命令` | 查看 / 修改指令开关 |
| `core强制执行文件备份` | 强制备份数据文件 |
| `core清除数据库` | 清空数据库（危险操作） |
| `core重置网页控制台密码` | 重置网页控制台密码 |
| `core重启` / `core关闭` | 重启 / 关闭 Core |
| `core更新` / `core强制更新` / `core设置镜像` / `core应用镜像` | Core 本体更新与镜像设置 |

### 权限管理（管理员）

| 指令 | 说明 |
| ---- | ---- |
| `core拉黑` / `core加入黑名单` | 拉黑用户 |
| `core取消拉黑` | 取消拉黑 |
| `core封禁` | 封禁用户 |

### AI 控制（管理员）

| 指令 | 说明 |
| ---- | ---- |
| `core清空会话` / `coreclear` | 清空 AI 会话上下文 |
| `core人格切换` / `corepersona` | 切换 AI 人格 |
| `core顺便一提` / `corebtw` | 追加一条不影响主上下文的说明 |
| `core禁言` / `coreban` | 禁止 AI 回复 |
| `core禁言状态` / `coreban状态` | 查看 AI 禁言状态 |
