# 三角洲

## 功能描述

三角洲行动数据查询：账号绑定、战绩查询、订阅推送与攻略查询等。

本页功能由 **GsCore（早柚核心）** 的 `DeltaUID` 插件提供，共 15 条指令。

::: tip 使用前提
1. 群聊需已开启 GsCore 相关功能（部分指令需 @机器人 或加前缀触发）。
2. 大部分查询需要先完成账号绑定，绑定方式见下方「账号绑定」分类。
3. 指令中标注 `需CK` 的表示需要先向 GsCore 提供对应平台的 Cookie/CK。
4. 发送 `三角洲帮助` 可让机器人在群内直接渲染帮助图。
:::

## 指令前缀

本插件支持的触发前缀：

| 前缀 | 说明 |
| ---- | ---- |
| `鼠鼠` | 该插件注册的触发前缀 |
| `ss` | 该插件注册的触发前缀 |

触发方式以「指令列表」中的 **示例** 列为准：示例里带了前缀的，实际发送时就需要带上。

## 指令列表

### 初始操作（2 条）

可以直接使用

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `登录` | 返回二维码登录信息 | `登录` |
| `绑定` | 绑定uid | `绑定` |

需要登录后使用,请输入指令`鼠鼠登录`

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `查询` | 返回三角洲烽火和战场信息 · `需CK` | `查询 烽火` |
| `战绩` | 返回烽火和战场历史对局信息 · `需CK` | `战绩 烽火` |
| `密码` | 查询今日密码 · `需CK` | `密码` |
| `特勤处` | 查询特勤处战绩 · `需CK` | `特勤处` |
| `藏馆` | 查询藏馆大红 · `需CK` | `藏馆` |
