# 英雄联盟

## 功能描述

英雄联盟数据查询：召唤师查询、战绩与对局记录查询。

本页功能由 **GsCore（早柚核心）** 的 `LOLegendsUID` 插件提供，共 7 条指令。

::: tip 使用前提
1. 群聊需已开启 GsCore 相关功能（部分指令需 @机器人 或加前缀触发）。
2. 大部分查询需要先完成账号绑定，绑定方式见下方「账号绑定」分类。
3. 指令中标注 `需CK` 的表示需要先向 GsCore 提供对应平台的 Cookie/CK。
4. 发送 `英雄联盟帮助` 可让机器人在群内直接渲染帮助图。
:::

## 指令前缀

本插件支持的触发前缀：

| 前缀 | 说明 |
| ---- | ---- |
| `lol` | 该插件注册的触发前缀 |

触发方式以「指令列表」中的 **示例** 列为准：示例里带了前缀的，实际发送时就需要带上。

## 指令列表

### 账号绑定（5 条）

绑定召唤师后即可查询战绩

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `lol绑定 <UID>` | 绑定你的英雄联盟 UID（先用 lol搜索 查到 UID） | `lol绑定Wuyi#12345` |
| `lol切换 <UID>` | 切换当前使用的 UID | `lol切换Wuyi#12345` |
| `lol删除 <UID>` | 删除已绑定的 UID | `lol删除Wuyi#12345` |
| `lol搜索 <召唤师名>` | 按召唤师名称搜索并获取 UID | `lol搜索Wuyi` |
| `lol添加CK <CK>` | 添加英雄联盟 CK（仅私聊） | `lol添加CK ...` |

### 查询服务（2 条）

查询召唤师数据

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `lol查询` | 查询召唤师基本信息 | `lol查询` |
| `lol对局记录` | 查询最近对局记录（别名：lol对战记录） | `lol对局记录` |
