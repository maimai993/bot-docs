# 王者荣耀

## 功能描述

王者荣耀数据查询：绑定营地 UID/CK 后可查询当前段位、最近战绩、巅峰赛与皮肤墙等。

本页功能由 **GsCore（早柚核心）** 的 `WzryUID` 插件提供，共 10 条指令。

::: tip 使用前提
1. 群聊需已开启 GsCore 相关功能（部分指令需 @机器人 或加前缀触发）。
2. 大部分查询需要先完成账号绑定，绑定方式见下方「账号绑定」分类。
3. 指令中标注 `需CK` 的表示需要先向 GsCore 提供对应平台的 Cookie/CK。
4. 发送 `王者帮助` 可让机器人在群内直接渲染帮助图。
:::

## 指令前缀

本插件支持的触发前缀：

| 前缀 | 说明 |
| ---- | ---- |
| `王者` | 该插件注册的触发前缀 |

触发方式以「指令列表」中的 **示例** 列为准：示例里带了前缀的，实际发送时就需要带上。

## 指令列表

### 基础服务（4 条）

需要先绑定uid

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `王者绑定uid` | 绑定你的王者UID | `王者绑定uid123456` |
| `王者删除uid` | 删除你的王者UID | `王者删除uid123456` |
| `王者切换uid` | 切换你的王者UID | `王者切换uid123456` |
| `王者添加CK` | 往数据库添加一个营地CK | `王者添加CK18-HU` |

### 查询服务（5 条）

查询一些基本信息, 需要营地打开陌生人可见

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `当前段位` | 基本段位信息一览 · `需CK` | `当前段位100740568` |
| `查荣耀` | 查询自己最近的王者战绩 · `需CK` | `查荣耀` |
| `查荣耀排位赛` | 查询自己最近的排位赛战绩 · `需CK` | `查荣耀排位赛` |
| `查荣耀巅峰赛` | 查询自己最近的巅峰赛战绩 · `需CK` | `查荣耀巅峰赛` |
| `皮肤墙` | 查询自己拥有的皮肤 · `需CK` | `皮肤墙` |

### 其他服务（1 条）

一些杂项服务

| 指令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `王者帮助` | 呼出该帮助界面 | `王者帮助` |
