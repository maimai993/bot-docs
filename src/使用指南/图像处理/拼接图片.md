# 拼接图片

## 功能描述
将多张图片拼接成一张长图，支持横向或纵向拼接

## 使用方法

### 指令名称

```
拼图 [方向]
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 方向 | 文本 | 否 | 拼接方向：横向/纵向，默认纵向 | 横向 |

### 操作流程

1. 输入 `拼图 [方向]` 开始拼接任务
2. 发送多张图片（支持一次性发送多张）
3. 输入 `完成` 或等待10秒自动开始拼接
