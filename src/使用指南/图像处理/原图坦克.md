# 原图坦克

## 功能描述
将两张图片合成为两帧GIF图片，实现查看原图图片切换效果

## 使用方法

### 指令名称

```
原图坦克
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 表图 | 图片/QQ号/@用户 | 否 | 第一帧图片（表图） | [图片] / 123456 / @用户 |
| 里图 | 图片/QQ号/@用户 | 否 | 第二帧图片（里图） | [图片] / 123456 / @用户 |
