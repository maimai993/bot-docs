# MC成就图

## 功能描述

生成 Minecraft 风格的成就/进度弹窗图片，可以自定义标题、描述与图标。

## 使用方法

### 指令名称

```
ament -t <标题> -d <描述>
```

指令名可在插件配置中修改（默认 `ament`）。

### 参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| `-t, --title <标题>` | 成就标题 | `ament -t 获得成就` |
| `-d, --description <描述>` | 成就描述 | `ament -d 你今天也很棒` |
| `-i, --icon <图标>` | 自定义图标（图片链接或伴随图片发送） | `ament -t 标题 -d 描述 -i` |
| `-m, --mcicon <关键词>` | 用 Minecraft 物品图标作为成就图标 | `ament -t 标题 -d 描述 -m diamond` |

::: tip 提示
也可以直接 **引用一张图片** 并发送指令，机器人会把它当作成就图标。
:::
