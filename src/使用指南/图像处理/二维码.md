# 二维码生成

## 功能描述
生成并发送二维码图片

## 使用方法

### 指令名称

```
qrcode <text>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| text | 文本 | 是 | 要编码为二维码的文本内容 | Hello World |

### 选项说明

| 选项 | 简写 | 参数 | 说明 | 默认值 |
|------|------|------|------|--------|
| margin | -m | number | 二维码边界尺寸 | 4 |
| scale | -s | number | 二维码缩放比例 | 4 |
| width | -w | number | 二维码图片大小 | - |
| dark | -d | color | 暗部颜色（二维码点颜色） | - |
| light | -l | color | 亮部颜色（背景颜色） | - |
