# AI图像处理

## 功能描述

基于 AI 的多功能图像处理插件，提供手办化、coser 化、Minecraft 化、线稿化等 **48 种风格**转换，并支持自定义提示词与多图融合。

## 使用方法

### 指令名称

```
image-prompt.<风格> [补充说明]
```

发送 `image-prompt` 可以查看所有可用风格。

### 参数说明

| 参数 | 说明 |
|------|------|
| 风格 | 需要的处理风格，见下方列表 |
| 补充说明 | 可选，额外的提示词内容 |

::: tip 提示
使用前请先 **发送一张图片**（或在指令中引用图片），机器人会对该图片进行风格转换。
:::

### 风格列表

| 分类 | 风格 |
|------|------|
| 手办 | 手办化、手办化2、手办化3、手办化4、手办化5、手办化6、玩偶化、微型化、挂件化、3D打印 |
| 角色 | coser化、cos化、cos自拍、cos相遇、真人化、真人化2、半真人、半融合、Q版化、角色界面、角色设定 |
| 场景 | 痛屋化、痛屋化2、痛车化、孤独的我、第一视角、第三视角、穿搭拆解、拆解图 |
| 风格化 | mc化、线稿化、贴纸化、鬼图、绘画四宫格 |
| 修复与合成 | 合并图片、修图、高清修复 |
| 网格与分镜 | 发型九宫格、头像九宫格、表情九宫格、多机位、电影分镜、动漫分镜、姿势表、三视图、人物转身 |
| 其他 | 爱上我了、玉足 |
