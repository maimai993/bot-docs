# VV评价

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-vv-bot)](https://www.npmjs.com/package/koishi-plugin-vv-bot)

**指令名称**: vv

**功能描述**: 搜索 VV 表情包

## 使用方法

### 指令名称

```
vv <关键词> [数量]
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 关键词 | 文本 | 是 | 要搜索的表情包关键词 | 可爱 |
| 数量 | 数字 | 否 | 返回的表情包数量 | 3 |
