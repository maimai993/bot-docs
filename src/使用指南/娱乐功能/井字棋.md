# 井字棋

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-tic-tac-toe)](https://www.npmjs.com/package/koishi-plugin-tic-tac-toe)

**指令名称**: ttt

**功能描述**: 群内井字棋对战小游戏

## 使用方法

### 指令名称

```
ttt.开始游戏
ttt.落子 <x> <y>
ttt.取消游戏
```

### 参数说明

| 指令 | 说明 |
|------|------|
| ttt.开始游戏 | 开始/加入一局井字棋游戏 |
| ttt.落子 `<x>` `<y>` | 在指定位置落子 |
| ttt.取消游戏 | 取消当前游戏 |
