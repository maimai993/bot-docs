# 做菜指南

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-smmcat-faqcooking)](https://www.npmjs.com/package/koishi-plugin-smmcat-faqcooking)

**指令名称**: 做菜指南

**功能描述**: 程序员在家做饭指南

## 使用方法

### 指令名称

```
做菜指南
做菜指南/做菜 <菜名>
做菜指南/做菜统计
做菜指南/做菜历史
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 菜名 | 文本 | 是 | 想要查询的菜名 | 西红柿炒鸡蛋 |
