# 保存QQ表情

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-emojihub-bili)](https://www.npmjs.com/package/koishi-plugin-emojihub-bili)

**指令名称**: 表情包

**功能描述**: 海量 B 站表情包搜索与发送，支持自定义表情包库

## 使用方法

### 指令名称

```
表情包 <表情包名称>
表情包/再来一张
表情包/随机表情包
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 表情包 `<名称>` | 发送指定表情包 |
| 表情包/再来一张 | 再来一张 |
| 表情包/随机表情包 | 随机获取表情包 |

可自定义添加任意表情包指令（如"2233娘小剧场表情包"、"随机emojihub表情包"等），每个指令都有上千张图片。
