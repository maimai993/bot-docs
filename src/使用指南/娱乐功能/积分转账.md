# 积分转账

## 功能描述
对接积分系统实现积分转账功能

## 使用方法

### 指令名称

```
转账 <金额> <用户>
转账平均 <金额> <用户列表>
转账随机 <金额> <用户列表>
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 转账 `<金额>` `<用户>` | 向指定用户转账积分 |
| 转账平均 `<金额>` `<用户>` | 向多个用户平均转账 |
| 转账随机 `<金额>` `<用户>` | 向多个用户随机转账 |
| 查看积分 | 查看自己的积分余额 |
