# 骂人文案

## 概述

**指令名称**: 骂

**功能描述**: 生成骂人风格文案

## 使用方法

### 指令名称

```
骂 [数量] [@用户]
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 数量 | 数字 | 否 | 骂的次数 | 2 |
| @用户 | @ | 否 | 要骂的群友 | @用户 |
