# 扮演游戏掷骰工具

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-trpgdice)](https://www.npmjs.com/package/koishi-plugin-trpgdice)

**指令名称**: roll

**功能描述**: TRPG 跑团掷骰工具，支持多种骰子表达式与属性检定

## 使用方法

### 指令名称

```
roll <骰子表达式> [理由]
rcheck <属性值> [理由]
rhide <表达式>
dnd [数量]
rcoin
```

### 参数说明

| 指令 | 说明 |
|------|------|
| roll `<表达式>` | 投掷骰子，如 roll 2d6+3 |
| rcheck `<属性值>` | 属性检定 |
| rhide `<表达式>` | 暗骰（隐藏结果） |
| dnd [数量] | DND 骰子 |
| rcoin | 掷硬币 |
