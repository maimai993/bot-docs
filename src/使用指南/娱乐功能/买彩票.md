# 买彩票

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-caipiao)](https://www.npmjs.com/package/koishi-plugin-caipiao)

**指令名称**: 买彩票

**功能描述**: 买张彩票看看你的运气吧，每次消耗5积分，最高奖励可达4999

## 使用方法

### 指令名称

```
买彩票
```

### 参数说明

本指令无需任何参数，输入后消耗5积分购买一张彩票。
