# 神断

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-divine-oracle)](https://www.npmjs.com/package/koishi-plugin-divine-oracle)

**指令名称**: 神断

**功能描述**: 神断占卜，抽取各种灵签，共八种灵签，本地抽取

## 使用方法

### 指令名称

```
神断
```

### 参数说明

本指令无需任何参数，输入后随机抽取一支灵签。
