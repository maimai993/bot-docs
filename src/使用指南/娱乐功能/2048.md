# 2048

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-number-merge-game)](https://www.npmjs.com/package/koishi-plugin-number-merge-game)

**指令名称**: 2048Game

**功能描述**: 群内2048数字合成小游戏

## 使用方法

### 指令名称

```
2048Game
2048Game.加入 [金额]
2048Game.开始 [棋盘大小]
2048Game.移动 <操作>
2048Game.退出
2048Game.排行榜
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 2048Game | 查看指令帮助 |
| 2048Game.加入 [金额] | 加入游戏 |
| 2048Game.开始 [棋盘大小] | 开始游戏 |
| 2048Game.移动 `<操作>` | 进行移动操作 |
| 2048Game.退出 | 退出游戏 |
| 2048Game.排行榜 | 查看排行榜 |
