# 2048

## 功能描述
群内2048数字合成小游戏

## 使用方法

### 指令名称

```
2048
2048.移动 <操作>
2048.结束
2048.排行
2048.记录 [@某人]
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 2048 |  开始2048游戏
| 2048.移动 `<操作>` | 进行移动操作 |
| 2048.结束 | 结束游戏 |
| 2048.排行 | 查看排行榜 |
| 2048.记录 [@某人] | 查看生涯成就 |
