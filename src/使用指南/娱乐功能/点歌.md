# 点歌

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-music-voice)](https://www.npmjs.com/package/koishi-plugin-music-voice)

**指令名称**: music

**功能描述**: 搜索网易云音乐的歌曲，交互后发送语音消息

## 使用方法

### 指令名称

```
music <关键词>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 关键词 | 文本 | 是 | 要搜索的歌曲名 | 晴天 |
