# 点歌

## 功能描述
搜索网易云音乐的歌曲，交互后发送语音消息

## 使用方法

### 指令名称

```
music <关键词>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 关键词 | 文本 | 是 | 要搜索的歌曲名 | 晴天 |
