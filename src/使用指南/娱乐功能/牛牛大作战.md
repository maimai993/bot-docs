# 牛牛大作战

## 功能描述
斗牛纸牌游戏

## 使用方法

### 指令名称

```
bullCard
bullCard.来一局
bullCard.排行榜
bullCard.强制结束
```

### 参数说明

| 指令 | 说明 |
|------|------|
| bullCard | 查看游戏帮助 |
| bullCard.来一局 | 发起斗牛游戏 |
| bullCard.排行榜 | 查看积分榜 |
| bullCard.强制结束 | 强制重置当前群游戏状态 |
