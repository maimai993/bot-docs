# 牛牛大作战

## 功能描述
斗牛纸牌游戏

## 使用方法

### 指令名称

```
impartpro
注入 [@某人]
保养
开导 [@某人]
牛牛决斗 [@某人]
重开牛牛
注入排行榜
牛牛排行榜
看看牛牛 [@某人]
锁牛牛 [@某人]
```

::: tip 指令名可自定义
插件在配置项里提供了 `commandList`，上面列的是**默认指令名**。
:::

### 参数说明

| 指令 | 说明 |
|------|------|
| `impartpro` | 查看插件帮助 |
| `注入` | 生成 / 初始化牛牛，可 @某人 |
| `保养` | 保养牛牛 |
| `开导` | 对指定用户使用，可 @某人 |
| `牛牛决斗` | 与其他用户决斗，可 @某人 |
| `重开牛牛` | 重开牛牛 |
| `注入排行榜` | 查看注入排行榜 |
| `牛牛排行榜` | 查看牛牛排行榜 |
| `看看牛牛` | 查看自己（或 @某人）的牛牛状态 |
| `锁牛牛` | 锁定牛牛（别名：开启牛牛大作战 / 关闭牛牛大作战） |
