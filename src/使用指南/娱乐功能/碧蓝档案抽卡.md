# 碧蓝档案抽卡

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-smmcat-baraffle)](https://www.npmjs.com/package/koishi-plugin-smmcat-baraffle)

**指令名称**: 蔚蓝抽卡

**功能描述**: 蔚蓝档案（碧蓝档案）国服抽卡模拟

## 使用方法

### 指令名称

```
蔚蓝抽卡.单抽
蔚蓝抽卡.十连
蔚蓝抽卡.记录
蔚蓝抽卡.统计
蔚蓝抽卡.信息
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 蔚蓝抽卡.单抽 | 单抽出奇迹 |
| 蔚蓝抽卡.十连 | 来一发十连出彩 |
| 蔚蓝抽卡.记录 | 查看我的抽卡记录 |
| 蔚蓝抽卡.统计 | 查看全部用户抽卡统计 |
| 蔚蓝抽卡.信息 | 查看当期卡池的UP信息 |
