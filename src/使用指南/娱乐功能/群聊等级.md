# 群聊等级

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-yutang-levelup)](https://www.npmjs.com/package/koishi-plugin-yutang-levelup)

**指令名称**: 查询等级 / level

**功能描述**: 群发言等级系统，支持等级查询与排行榜

## 使用方法

### 指令名称

```
查询等级
level
发言等级排行榜
跨群等级排行榜
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 查询等级 | 查看自己的发言等级 |
| level | 查看等级（英文指令） |
| 发言等级排行榜 | 查看本群等级排行 |
| 跨群等级排行榜 | 查看跨群等级排行 |
