# 邦多利猜猜歌

## 功能描述
邦多利（BanG Dream!）猜猜歌小游戏，支持缓存和别名机制

## 使用方法

### 指令名称

```
ccg
ccg.answer
ccg.stop
ccg.tips
```

### 参数说明

| 指令 | 说明 |
|------|------|
| ccg | 开始猜歌 |
| ccg.answer | 作答 |
| ccg.stop | 停止游戏 |
| ccg.tips | 查看提示 |
