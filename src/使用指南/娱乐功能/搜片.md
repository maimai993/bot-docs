# 搜片

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat)

**指令名称**: jav

**功能描述**: 通过番号搜索影片，可获取磁链封面及缩略图，支持关键词搜索与最新影片列表

::: warning
本功能仅限私聊使用，且需要配置相应权限。
:::

## 使用方法

### 指令名称

```
jav <番号>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 番号 | 文本 | 是 | 影片番号 | ABC-123 |
