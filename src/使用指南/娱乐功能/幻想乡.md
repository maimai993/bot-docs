# 幻想乡

## 功能描述

一个群内文字 RPG：注册角色后可以在地图中移动、遇敌战斗、组队、学习技能、穿戴装备，还能把金币存进银行。

## 使用方法

### 指令名称

```
幻想乡
```

发送 `幻想乡` 可以查看主菜单。所有子功能都以 `幻想乡` 为根指令，也可直接发送子指令。

## 指令列表

### 角色

| 指令 | 说明 |
|------|------|
| `幻想乡` | 查看主菜单 |
| `开始注册` | 注册一个幻想乡角色 |
| `位置` | 查看自己当前所在位置 |
| `个人属性` | 查看自己的属性面板 |
| `个人道具` | 查看自己的道具 |
| `个人货币` | 查看自己的货币 |
| `他人属性 <username>` | 查看其他玩家的属性 |

### 移动与地图

| 指令 | 说明 |
|------|------|
| `移动.上` / `移动.下` / `移动.左` / `移动.右` | 向对应方向移动 |
| `地图` | 查看当前地图 |
| `传送 <floor>` | 传送到指定楼层 |
