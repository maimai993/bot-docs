# 鹿管签到

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-deer-pipe)](https://www.npmjs.com/package/koishi-plugin-deer-pipe)

**指令名称**: 鹿管签到

**功能描述**: 日历效果的签到插件，支持签到道具、排行榜、补签等

## 使用方法

### 指令名称

```
鹿管签到
鹿管签到/鹿 [用户]
鹿管签到/帮鹿 [用户]
鹿管签到/看鹿 [用户]
鹿管签到/鹿榜
鹿管签到/补鹿 [日期] [用户]
鹿管签到/戒鹿 [日期]
鹿管签到/鹿管购买 [道具]
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 鹿管签到 | 每日签到 |
| 鹿管签到/鹿 [用户] | 查看用户签到日历 |
| 鹿管签到/帮鹿 [用户] | 帮助用户签到 |
| 鹿管签到/鹿榜 | 查看签到排行榜 |
| 鹿管签到/补鹿 [日期] [用户] | 补签某日 |
| 鹿管签到/戒鹿 [日期] | 取消某日签到 |
| 鹿管签到/鹿管购买 [道具] | 购买签到道具 |
