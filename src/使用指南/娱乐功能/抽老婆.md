# 抽老婆

## 功能描述
抽取今日群友老婆，支持求婚、强娶、离婚等互动

## 使用方法

### 指令名称

```
娶群友
求婚
离婚
换老婆
查老婆
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 娶群友 | 随机抽取今日群友老婆 |
| 求婚 | 向心仪的群友求婚 |
| 离婚 | 解除关系 |
| 换老婆 | 换一个老婆 |
| 查老婆 | 查询有没有老婆 |
