# 抽老婆

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-waifu)](https://www.npmjs.com/package/koishi-plugin-waifu)

**指令名称**: 娶群友

**功能描述**: 抽取今日群友老婆，支持求婚、强娶、离婚等互动

## 使用方法

### 指令名称

```
娶群友
求婚
强娶
离婚
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 娶群友 | 随机抽取今日群友老婆 |
| 求婚 | 向心仪的群友求婚 |
| 强娶 | 强行迎娶（需要权限2） |
| 离婚 | 解除关系（每日限6次） |
