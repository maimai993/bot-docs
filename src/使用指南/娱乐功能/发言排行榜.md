# 发言排行榜

## 功能描述
消息数量统计，生成各种发言排行榜

## 使用方法

### 指令名称

```
messageCounter.排行榜 [数量]
messageCounter.群排行榜 [数量]
messageCounter.查询 [用户]
```

### 参数说明

| 指令 | 说明 |
|------|------|
| messageCounter.排行榜 [数量] | 查看用户发言排行榜 |
| messageCounter.群排行榜 [数量] | 查看群发言排行榜 |
| messageCounter.查询 [用户] | 查询指定用户的发言次数 |
| messageCounter.初始化 | 初始化数据（需要权限） |
