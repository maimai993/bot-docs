# 回应表情

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat)

**指令名称**: 表情回应

**功能描述**: 为触发指令的消息添加回应表情，支持表情搜索与随机表情

## 使用方法

### 指令名称

```
表情回应 [表情ID]
表情回应.随机 [数量]
表情回应.搜索 <关键词>
表情回应.列表
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 表情回应 [表情ID] | 发送指定表情 |
| 表情回应.随机 [数量] | 随机发送表情 |
| 表情回应.搜索 `<关键词>` | 搜索表情 |
| 表情回应.列表 | 查看表情列表 |
