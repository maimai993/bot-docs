# 方言接龙

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-dialect-game)](https://www.npmjs.com/package/koishi-plugin-dialect-game)

**指令名称**: 方言接龙

**功能描述**: 方言接龙小游戏，支持难度设置与自定义题目

## 使用方法

### 指令名称

```
方言接龙
参加
开始游戏 [难度]
游戏状态
设置默认难度 <难度>
添加题目 <内容>
退出
中止游戏
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 方言接龙 | 查看游戏帮助 |
| 参加 | 参加游戏 |
| 开始游戏 [难度] | 开始游戏 |
| 设置默认难度 `<难度>` | 设置默认难度 |
| 添加题目 `<内容>` | 添加自定义题目 |
| 游戏状态 | 查看游戏状态 |
| 退出 / 中止游戏 | 退出或中止游戏 |
