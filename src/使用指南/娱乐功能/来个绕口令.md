# 来个绕口令

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-tongue-twister-picker)](https://www.npmjs.com/package/koishi-plugin-tongue-twister-picker)

**指令名称**: 来个绕口令

**功能描述**: 随机抽取一条绕口令，共755条

## 使用方法

### 指令名称

```
来个绕口令
```

### 参数说明

本指令无需任何参数，输入后随机输出一条绕口令。
