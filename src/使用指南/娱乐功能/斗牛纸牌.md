# 斗牛纸牌

## 功能描述

群内斗牛纸牌小游戏。每人发五张牌，JQK 记 10 点、A 记 1 点；任选三张凑成 10 的倍数即为「有牛」，剩余两张的点数之和的个位数就是牛几；凑不齐则「没牛」。

支持 **娱乐模式**（发送暗号参与，默认 `1`）与 **金币模式**（发送下注金额参与）。

特殊牌型：四炸、五花牛、五小牛。

## 使用方法

### 指令名称

```
bull
bull.来一局
bull.排行榜 [数量]
bull.强制结束
```

### 参数说明

| 指令 | 说明 |
|------|------|
| `bull` | 查看玩法帮助 |
| `bull.来一局` | 发起一局，等待时间内其他人群内加入 |
| `bull.排行榜 [数量]` | 查看排行榜，可指定显示条数 |
| `bull.强制结束` | 强制重置当前对局（需要权限 2） |

### 金币模式赔率

| 牌型 | 赔率 |
|------|------|
| 五小牛 / 五花牛 / 四炸 | ×4 |
| 牛牛 | ×3 |
| 牛七 ~ 牛九 | ×2 |
| 其余 | ×1 |
