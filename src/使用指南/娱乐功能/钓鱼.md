# 钓鱼

## 功能描述
群内钓鱼小游戏，支持鱼塘、鱼竿升级、烹饪等丰富玩法

## 使用方法

### 指令名称

```
钓鱼
开始钓鱼
查看鱼塘
钓鱼卖出 <鱼> <数量>
钓鱼鱼竿
升级鱼竿
钓鱼烹饪 <料理>
钓鱼库存
钓鱼成就
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 钓鱼 | 查看游戏帮助 |
| 开始钓鱼 | 开始钓鱼吧 |
| 查看鱼塘 | 查看群鱼塘的信息 |
| 钓鱼卖出 `<鱼>` `<数量>` | 卖出自己库存的鱼 |
| 钓鱼鱼竿 | 查看鱼竿 |
| 升级鱼竿 | 升级你持有的鱼竿 |
| 钓鱼烹饪 `<料理>` | 使用鱼进行烹饪制作道具 |
| 钓鱼库存 | 查看用户收获的鱼类库存 |
| 钓鱼成就 | 查看钓鱼成就 |
