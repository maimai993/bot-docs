# 猜词

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-wordle-game)](https://www.npmjs.com/package/koishi-plugin-wordle-game)

**指令名称**: wordleGame

**功能描述**: 猜单词游戏，支持经典、汉兜、词影、Numberle、Math、Lewdle 等多种模式

## 使用方法

### 指令名称

```
wordleGame
wordleGame.加入 [金额]
wordleGame.开始.经典
wordleGame.猜 <单词>
wordleGame.查单词 <单词>
```

### 参数说明

| 指令 | 说明 |
|------|------|
| wordleGame | 查看游戏帮助 |
| wordleGame.加入 [金额] | 加入游戏 |
| wordleGame.开始.经典 | 开始经典猜单词游戏 |
| wordleGame.猜 `<单词>` | 做出一次猜测 |
| wordleGame.查单词 `<单词>` | 查询单词释义 |
| wordleGame.玩法介绍 | 游戏玩法介绍 |
