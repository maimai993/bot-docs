# 猜词

#功能描述
猜单词/成语游戏，支持经典、汉兜、词影、Numberle、Math、Lewdle 等多种模式，内置排行榜与积分系统。

---

## 完整指令列表

### 基础操作

| 指令 | 说明 |
|------|------|
| `wordleGame` | 查看游戏帮助 |
| `wordleGame.加入 [金额]` | 加入游戏，可选下注金额（若启用积分系统） |
| `wordleGame.改名 <新名字>` | 修改游戏内显示名称 |
| `wordleGame.退出` | 退出当前游戏 |
| `wordleGame.结束` | 强制结束当前对局 |
| `wordleGame.玩法介绍` | 查看详细玩法说明 |

### 开始游戏

| 指令 | 说明 |
|------|------|
| `wordleGame.开始.经典` | 开始经典模式（5字母英文单词） |
| `wordleGame.开始.汉兜` | 开始汉兜模式（中文成语/词语） |
| `wordleGame.开始.词影` | 开始词影模式（根据释义猜词） |
| `wordleGame.开始.lewdle` | 开始 Lewdle 模式（不雅/俚语单词） |
| `wordleGame.开始.numberle` | 开始 Numberle 模式（猜数字） |
| `wordleGame.开始.math` | 开始 Math 模式（猜数学表达式） |

### 游戏进行

| 指令 | 说明 |
|------|------|
| `wordleGame.猜 <内容>` | 做出一次猜测（单词/成语/数字等） |
| `wordleGame.查成语 <成语>` | 查询成语释义（支持百度汉语、汉典源） |
| `wordleGame.查单词 <单词>` | 查询英文单词释义 |
| `wordleGame.查单词.all <单词>` | 查询单词所有释义（详细版） |
| `wordleGame.查单词.wordword <单词>` | 查询单词的单词书信息 |
| `wordleGame.单词查找器 <关键词>` | 模糊查找匹配的单词 |
| `wordleGame.拼音速查表` | 查看拼音速查表（汉兜模式辅助） |
| `wordleGame.查询进度` | 查看当前对局进度 |
| `wordleGame.查询玩家记录` | 查看个人历史战绩 |

## 快捷输入

所有指令前缀 `wordleGame` 可缩写为 `wordlegame`（不区分大小写），例如：

- `wordlegame.开始.经典`
- `wordlegame.猜 hello`
- `wordlegame.排行榜.总.胜场`

## 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `[金额]` | 整数（可选） | 加入游戏时的初始下注积分，不填则使用默认值 |
| `<内容>` | 字符串（必填） | 猜测的内容，如单词 `hello` 或成语 `一心一意` |
| `<新名字>` | 字符串（必填） | 修改后的显示名称 |
| `<关键词>` | 字符串（必填） | 单词查找器的搜索关键词 |

## 常见问题

**Q: 如何开始一局游戏？**  
A: 先使用 `wordleGame.加入 [金额]` 加入游戏，然后使用 `wordleGame.开始.经典` 等命令选择模式。

**Q: 猜词有什么反馈？**  
A: 每次猜测后，游戏会以颜色或符号提示字母/字符的位置是否正确（类似 Wordle 规则）。

**Q: 汉兜模式怎么玩？**  
A: 汉兜模式为中文成语/词语猜谜，可使用 `wordleGame.拼音速查表` 辅助判断拼音匹配情况。

**Q: 如何退出游戏？**  
A: 使用 `wordleGame.退出` 即可退出当前对局。

**Q: 排行榜数据多久更新？**  
A: 每局游戏结束后实时更新。
