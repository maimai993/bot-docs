# 中国象棋

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-cchess)](https://www.npmjs.com/package/koishi-plugin-cchess)

**指令名称**: cchest

**功能描述**: 群内中国象棋对弈，支持人人/人机对战

## 使用方法

### 指令名称

```
cchess
cchess.加入 [红|黑]
cchess.开始.人人对战
cchess.开始.人机对战
cchess.移动 <移动操作>
cchess.悔棋.请求
```

### 参数说明

| 指令 | 说明 |
|------|------|
| cchest | 查看指令帮助 |
| cchest.加入 [红\|黑] | 加入游戏并选择红黑方 |
| cchest.开始.人人对战 | 开始人人对战 |
| cchest.开始.人机对战 | 开始人机对战 |
| cchest.移动 `<操作>` | 进行移动操作 |
| cchest.悔棋.请求 | 请求悔棋 |
| cchest.结束 | 强制结束游戏 |
