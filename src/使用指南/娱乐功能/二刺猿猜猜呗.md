# 二刺猿猜猜呗

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-anime-ccb)](https://www.npmjs.com/package/koishi-plugin-anime-ccb)

**指令名称**: ccb

**功能描述**: 二次元角色猜猜游戏，根据提示猜测动漫角色

## 使用方法

### 指令名称

```
ccb
搜角色 <角色关键词>
搜作品 <作品关键词>
作品搜角色 <作品ID>
提示
bzd
```

### 参数说明

| 指令 | 说明 |
|------|------|
| ccb | 开始猜角色游戏 |
| 搜角色 `<关键词>` | 搜索角色 |
| 搜作品 `<关键词>` | 搜索作品ID |
| 作品搜角色 `<作品ID>` | 查询对应作品的出场角色 |
| 提示 | 获得答案角色随机一个标签 |
| bzd | 结束本次游戏并获取答案 |

发送查询到的角色ID即可答题，箭头↑↓表示答案数值偏大偏小。
