# 今天吃什么

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-eat-what)](https://www.npmjs.com/package/koishi-plugin-eat-what)

**指令名称**: eat / drink

**功能描述**: 随机推荐今天吃什么、喝什么

## 使用方法

### 指令名称

```
eat
drink
```

### 参数说明

本指令无需任何参数，输入后随机推荐一种食物或饮品。
