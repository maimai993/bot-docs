# 四级词汇

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-gyyg-cet4vocabulary)](https://www.npmjs.com/package/koishi-plugin-gyyg-cet4vocabulary)

**指令名称**: cet4

**功能描述**: 输出英语四级词汇，群聊中偷偷背英语，卷死群友

## 使用方法

### 指令名称

```
cet4
```

### 参数说明

本指令无需任何参数，输入后随机输出一个英语四级词汇及释义。
