# 赛马

## 功能描述
群内赛马小游戏，支持押注与道具

## 使用方法

### 指令名称

```
赛马
赛马/准备赛马
赛马/开始赛马
赛马/押 <名次> <金额>
赛马/赛马余额
赛马/使用道具 <道具> <目标>
赛马/结束赛马
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 赛马 | 查看游戏帮助 |
| 赛马/准备赛马 | 准备一场赛马吧 |
| 赛马/开始赛马 | 开始进行赛马 |
| 赛马/押 `<名次>` `<金额>` | 猜测哪个马冠军 |
| 赛马/赛马余额 | 查看当前余额 |
| 赛马/使用道具 `<道具>` `<目标>` | 对指定目标使用道具 |
| 赛马/赛马道具 | 查看赛马道具信息 |
| 赛马/结束赛马 | 强制结束赛马 |
