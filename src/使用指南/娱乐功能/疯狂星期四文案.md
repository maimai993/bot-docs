# 疯狂星期四文案

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-crazy-thursday)](https://www.npmjs.com/package/koishi-plugin-crazy-thursday)

**指令名称**: 疯狂星期四 / thursday

**功能描述**: 随机输出 KFC 疯狂星期四段子

## 使用方法

### 指令名称

```
疯狂星期四
```

也可以直接输入：

```
thursday
```

### 参数说明

本指令无需任何参数，输入后直接随机输出一条 KFC 疯狂星期四段子。
