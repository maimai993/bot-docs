# 语音倒放

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-audio-reverse)](https://www.npmjs.com/package/koishi-plugin-audio-reverse)

**指令名称**: audio-reverse

**功能描述**: 对语音进行倒放

## 使用方法

### 指令名称

```
audio-reverse
```

### 参数说明

发送语音消息后输入指令，即可将该语音倒放。
