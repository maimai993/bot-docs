# 视频解析

::: caution 该功能由于服务器网络波动已暂时失效
:::

## 功能描述

解析抖音、B站、快手、小红书的分享链接，把视频、图文、热评渲染成适合群聊直接看的图片；
QQ 上还会先回一条带按钮的面板，选集、选画质、查进度都能点按钮完成。

| 平台 | 自动解析 | 评论区 | 动态推送 | 扫码登录 |
| --- | :-: | :-: | :-: | :-: |
| 抖音 | ✓ | ✓ | ✓ | ✓ |
| B站 | ✓ | ✓ | ✓ | ✓ |
| 快手 | ✓ | ✓ | — | — |
| 小红书 | ✓ | ✓ | — | — |

## 使用方法

### 指令名称

直接发平台分享链接就会自动识别解析；也可以引用一条消息后再发指令：

```
解析
kkk解析
弹幕解析
```

- `解析` / `kkk解析`：解析作品（QQ 上先出交互面板）
- `弹幕解析`：把 B站 / 抖音弹幕烧进视频，需要**引用**一条消息使用

指令前缀按机器人本身的配置来，上面写的是不带前缀的写法。

### 参数说明

| 参数 | 说明 |
| --- | --- |
| `--qn=80` | B站画质（80 = 1080P，116 = 1080P60，120 = 4K） |
| `--q=1080p` | 抖音画质 |
| `--dm=1` | 烧录弹幕 |
| `--panel=1` | 只重发面板 |
| `--bgp=2` | 番剧分集翻页 |

面板上的按钮点的就是这些参数，一般不用手动敲。

## 常用指令

| 指令 | 说明 |
| --- | --- |
| `kkk帮助` | 查看当前命令菜单 |
| `抖音登录` / `B站登录` | 扫码获取并写入平台 Cookie |
| `设置抖音推送 <抖音号>` | 订阅或取消订阅抖音创作者 |
| `设置B站推送 <UID>` | 订阅或取消订阅B站创作者 |
| `抖音推送列表` / `B站推送列表` | 查看当前推送列表 |
| `kkk解析统计` | 查看当前群解析统计 |
| `kkk全局解析统计` | 查看全局解析趋势（仅主人可用） |
| `kkk版本` | 查看运行环境诊断卡片 |
| `卡片消息` | 解析转发过来的分享卡片 |

## QQ 上的交互面板

1. 发链接后先回一条面板：列出各档画质和体积，体积超过上限的档位不显示；
2. 点选画质后才开始下载：撤回上一条面板 → 「收到请求，开始下载」+「查询下载进度」按钮 → 「发送中…」→ 视频；
3. 全程只保留最新一条机器人消息，旧面板会自动撤回；面板按钮是无状态的，机器人重启后点旧面板依然可用。

番剧会先出分集表格（默认 5×4、倒序），表格下方是「上一页 / 第 x/y 页 / 下一页」。

## 输出说明

- **长图**（评论区）默认按普通图片发送，只有超过 20MB 或者发送失败时才会自动切成几片，再用一条消息拼回一整张；
- **图集**会把多张图合并成一条消息发送，实况视频跟在后面单独发；
- **画质**依赖登录态：没配 Cookie 时只拿到基础画质，扫码登录后才会尝试更高的清晰度。
