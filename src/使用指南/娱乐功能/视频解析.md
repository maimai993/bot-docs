# 视频解析

::: caution 该功能由于服务器网络波动已暂时失效
:::
## 功能描述
解析抖音、B站、快手、小红书等平台的视频/图文分享链接，提取内容并渲染成图片

## 使用方法

### 指令名称

发送平台分享链接后会自动识别解析，也可以引用消息后发送：

```
#解析
#kkk解析
#弹幕解析
```

### 常用指令

| 指令 | 说明 |
|------|------|
| #kkk帮助 | 查看当前命令菜单 |
| #抖音登录 | 扫码获取并写入抖音 Cookie |
| #B站登录 | 扫码获取并写入B站 Cookie |
| #设置抖音推送 `<抖音号>` | 订阅或取消订阅抖音创作者 |
| #设置B站推送 `<UID>` | 订阅或取消订阅B站创作者 |
| #kkk解析统计 | 查看当前群解析统计 |
| #kkk全局解析统计 | 查看全局解析趋势（仅主人可用） |
| #kkk版本 | 查看当前版本 |
