# 颜色游戏

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-color-ident)](https://www.npmjs.com/package/koishi-plugin-color-ident)

**指令名称**: 色彩识别

**功能描述**: 色彩识别小游戏，测试你的颜色识别能力

## 使用方法

### 指令名称

```
色彩识别 [位置]
```

### 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| 位置 | 文本 | 游戏中要识别的颜色位置 |
