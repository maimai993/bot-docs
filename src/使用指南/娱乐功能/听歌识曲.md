# 听歌识曲

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-smmcat-hummingidentify)](https://www.npmjs.com/package/koishi-plugin-smmcat-hummingidentify)

**指令名称**: 切换识别源

**功能描述**: 哼唱识别，通过哼唱的旋律识别歌曲

## 使用方法

### 指令名称

```
切换识别源 <识别源类型>
```

### 参数说明

发送一段哼唱或播放歌曲的语音后，机器人会识别出对应的歌曲。可通过"切换识别源"切换不同的识别服务。

| 参数 | 类型 | 说明 |
|------|------|------|
| 识别源类型 | 文本 | 要切换的识别服务类型 |
