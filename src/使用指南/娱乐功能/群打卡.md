# 群打卡

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat)

**指令名称**: 一键打卡

**功能描述**: 一条指令完成每日打卡，自动执行签到、鹿管、开导等系列打卡操作

## 使用方法

### 指令名称

```
一键打卡
```

### 参数说明

本指令无需任何参数，输入后自动依次执行配置好的打卡操作（如签到、鹿管签到、开导等）。
