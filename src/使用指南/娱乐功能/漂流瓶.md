# 漂流瓶

## 概述
[![](https://img.shields.io/badge/框架-koishi-5445a2?style=flat)](https://koishi.chat) [![](https://img.shields.io/npm/v/koishi-plugin-re-driftbottle)](https://www.npmjs.com/package/koishi-plugin-re-driftbottle)

**指令名称**: 漂流瓶

**功能描述**: 跨群扔漂流瓶，你的漂流瓶会被谁看到呢？还可以评论漂流瓶

## 使用方法

### 指令名称

```
漂流瓶
漂流瓶.扔漂流瓶 <内容>
漂流瓶.捞漂流瓶
漂流瓶.评论瓶子 <瓶子ID> <评论>
漂流瓶.查看我的瓶子
漂流瓶.瓶子黄页
漂流瓶.精选瓶子
```

### 参数说明

| 指令 | 说明 |
|------|------|
| 漂流瓶 | 查看漂流瓶信息 |
| 漂流瓶.扔漂流瓶 `<内容>` | 扔出一个漂流瓶 |
| 漂流瓶.捞漂流瓶 | 捞起一个漂流瓶 |
| 漂流瓶.评论瓶子 `<瓶子ID>` `<评论>` | 评论漂流瓶 |
| 漂流瓶.查看我的瓶子 | 查看自己扔的瓶子 |
| 漂流瓶.瓶子黄页 | 查看瓶子黄页 |
| 漂流瓶.精选瓶子 | 查看精选瓶子 |
